ARCHITECTURE GUIDE

Language proposes

Normalization, vocabulary matching, candidate scoring, references and constraints produce a typed action graph. Confidence is interpretation evidence, not permission.

Commerce authorizes

The gateway owns customer identity, scoped capabilities, prices, stock and mutation receipts. The assistant must respect those boundaries on every turn.

Evidence closes the loop

Streaming events, captured routing reports and timing measurements show what happened. A green parser test does not establish a successful checkout.
