# Maintenance

Inventory, cleanup, data repair, and output directory helpers live here. These commands can change local or demo data, so inspect their arguments and target before running them. SQL files are task-specific inputs, not general migration scripts.

Use the [command reference](../../../commerce-docs/platform/reference/scripts.md) for supported entry points and the [demo seeding task](../../tasks/demo-seeding.md) for catalog refresh work.
