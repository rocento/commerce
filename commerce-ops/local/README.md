# Workstation operations

Use [platform](platform/README.md) for the shared commerce stack and local
assistant setup, [onboarding](onboarding/README.md) for the isolated onboarding
dependencies, and [preview](preview/README.md) for the native preview proxy.
The [task guides](../tasks/README.md) give the startup order and service owners.

These commands use local Compose projects and configuration. The shared
assistant topology they select lives in [Compose](../compose/README.md).
Use `python3 commerce-ops/bin/ops local ...` for the public platform and
onboarding lifecycle commands.
