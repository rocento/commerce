# Developer tool editing rules

Keep contract sources with their applications. Preserve generator output and
CLI behavior during moves. Inspect repository discovery, scratch-copy fixtures,
sibling imports, generated provenance, CI and release preflight dependencies.
Update `../config/entrypoints.json`, callers and upload filters together.
Run affected tests in `../tests/operations/`; generate in temporary fixtures
instead of overwriting unrelated source or retained evidence. Follow the root
agent guide for compatibility, documentation and production boundaries.
