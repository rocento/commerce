# Contracts

Generators and synchronizers for OpenAPI, assistant, planning, theme, and interface contracts live here. Run the relevant generator from the repository root, then review its generated diff with the owning application. The [command reference](../../../commerce-docs/platform/reference/scripts.md) lists public entry points.

Contract sources remain with their service owners; these scripts keep generated copies aligned. Do not edit a generated output in place without updating its source.
