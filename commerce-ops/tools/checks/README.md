# Checks

Repository policy checks and targeted integration or smoke checks live here. Start with the [command reference](../../../commerce-docs/platform/reference/scripts.md) for supported invocations. Some integration checks need a running API or database; inspect a script's arguments before pointing it at an environment.

`check-documentation.py` checks maintained guides and links. Architecture and migration checks inspect source or database migration history. Scenario scripts exercise specific commerce behavior and may write test data.
